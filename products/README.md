# 正式产品 / Approved Products

这里保存已经正式批准的量化产品。

This folder contains formally approved quantitative products.

## 目录结构 / Structure

每个产品使用独立目录：

products/<product-name>/

每个正式版本保存在：

products/<product-name>/releases/<version>/

示例：

products/qqq-typical-price/releases/v1.0.0/

## 重要规则 / Important Rule

旧版本不得覆盖。

产品发生任何修改时，必须建立新的版本目录。
